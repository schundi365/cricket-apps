# How to Convert the Report to PDF

I've created a comprehensive report file: `MK_Air_CC_Performance_Analysis_Report.md`

Here are several ways to convert it to PDF:

## Option 1: Using Pandoc (Recommended)
If you have Pandoc installed:
```bash
pandoc MK_Air_CC_Performance_Analysis_Report.md -o MK_Air_CC_Performance_Analysis_Report.pdf
```

## Option 2: Using Visual Studio Code
1. Open the .md file in VS Code
2. Install "Markdown PDF" extension
3. Right-click in the file and select "Markdown PDF: Export (pdf)"

## Option 3: Using Online Converters
1. Go to any online markdown to PDF converter like:
   - https://www.markdowntopdf.com/
   - https://dillinger.io/ (export as PDF)
   - https://pandoc.org/try/
2. Copy and paste the content or upload the .md file
3. Download the generated PDF

## Option 4: Using Chrome/Edge Browser
1. Open the .md file in a markdown viewer or GitHub
2. Use browser's "Print" function (Ctrl+P)
3. Select "Save as PDF" as destination

## Option 5: Using Microsoft Word
1. Open Word
2. Go to File > Open
3. Select the .md file (change file type to "All Files")
4. Save as PDF

The markdown file is properly formatted with headers, tables, and sections that will convert nicely to PDF format.
